# 拾光 · 生活工作台

一个集成式生活工作台，包含七大模块：

- **今日概览** — 今日待办、习惯打卡、预算余量、最新体重一站看清
- **记账理财** — 收支记录、预算管理、月度对比、分类筛选、消费结构环图
- **习惯健康** — 自定义习惯（勾选 / 计数 / 数值三种打卡方式）+ 30 天热力图
- **减脂健身** — 体重体脂记录、7 日均线、BMI、目标进度、热量缺口、自定义周计划
- **日程统筹** — 逾期 / 今日 / 未来日程分组管理
- **待买清单** — 待购合计、优先级、购买勾选
- **书影音收藏** — 状态、星级、短评、封面墙 / 列表双视图、年度统计

## 数据说明

所有数据实时存储于云端资料库数据表（共 9 张表），新增、修改、删除即时写回；
